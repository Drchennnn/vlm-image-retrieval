# 基于预训练视觉语言模型的自然语言图像检索

## 项目目标

本项目旨在研究如何使用预训练视觉语言模型进行自然语言图像检索。

系统计划支持两个检索方向：

1. **文本到图像检索：** 给定自然语言查询，从图像集合中检索最相关的图像。
2. **图像到文本检索：** 给定图像，从文本集合中检索最相关的标题或文本描述。

项目重点是理解预训练视觉和文本表示如何用于跨模态相似度搜索；当前阶段不声称系统已经完成。

## 计划中的基线：CLIP

初始基线计划使用 CLIP 或兼容的预训练 CLIP 实现。具体模型系列、检查点和版本**待决定**。

CLIP 包含：

- 将图像映射为向量表示的**图像编码器**；
- 将文本描述映射为向量表示的**文本编码器**。

两个编码器经过训练，使匹配的图像和文本在共享表示空间中更接近，不匹配的组合更远。编码并归一化后，可以用余弦相似度或等价的点积估计图文相似度。

检索过程如下：

- 文本到图像检索：嵌入文本查询，再按相似度对图像嵌入排序。
- 图像到文本检索：嵌入图像查询，再按相似度对文本嵌入排序。

### 对比预训练

对于一批配对样本，每张图像对应一个文本。模型计算该批次中所有图像嵌入与所有文本嵌入之间的相似度矩阵。对角线上的匹配组合是正样本对，其余组合作为批内负样本。

随后使用对称式对比目标：

- 提高正确图文对的相似度；
- 降低错误图文组合的相似度；
- 学习支持跨模态匹配的共享空间。

原始 CLIP 论文将这种方法描述为基于从互联网收集的大规模图文对进行预训练。该训练设置属于论文背景，不意味着本项目当前包含相同数据、模型权重或使用权限。

## Winoground 评估

Winoground 计划作为组合式视觉语言理解的额外评估集。

与普通检索基准不同，Winoground 包含用于测试模型是否理解组合结构的图像和标题配对，包括词序和关系变化。其样本要求模型在两个图像和两个标题之间进行匹配；这些标题使用相同或相近的词，但排列方式不同。

项目计划将 Winoground 用作：

- 探测性评估和压力测试；
- 检查总体检索指标可能掩盖的组合式失败；
- 定性错误分析的潜在来源。

默认情况下，Winoground**不作为训练集**。若未来实验改变用途，必须单独定义并记录。

Winoground 论文报告了文本、图像和组别分数。是否在本项目中完全复现这些指标，以及评估实现和数据访问方式，均**待决定**。

## 可选的后续改进

可能的后续方向包括：

- 提示词集成或提示模板分析；
- 检索中的困难负样本挖掘；
- 使用第二个模型对检索候选进行重排序；
- 轻量微调或基于适配器的适应；
- 比较多个预训练检查点；
- 按标题长度、关系类型或组合类别进行分析；
- 改进索引和检索效率；
- 多语言或特定领域检索。

这些是可选的未来方向，不是首次实现的承诺。
