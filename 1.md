***[Multi-Modal] ***Image Retrieval with Natural Language

Build a system that searches for images based on natural language descriptions. You main task is to utilize a pre-trained [vision-language common representation (feature) space**Links to an external site.**](https://arxiv.org/pdf/2103.00020) for cross-modal retrieval, i.e., using language to retrieve image or use image to retrieve language. Note, you are not asked to train a foundation model from scratch by yourself. Instead, you should analyze the concept of contrastive pre-training and explain how it works. Then, you can choose to finetune your model on some specific or challenging datasets such as [winoground**Links to an external site.**](https://arxiv.org/pdf/2204.03162) to improve the performance.
